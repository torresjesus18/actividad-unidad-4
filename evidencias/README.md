# Evidencias de funcionamiento

Guarda aquí capturas auténticas tomadas al ejecutar el proyecto. No se incluyen imágenes de demostración ni resultados simulados.

Capturas sugeridas:

1. Interfaz principal del chat.
2. Dos usuarios conectados y visibles en la lista.
3. Intercambio de mensajes reflejado en ambos clientes.
4. Indicador de escritura.
5. Aviso de entrada o desconexión.
6. Interfaz en tamaño móvil.
7. Terminal con el servidor iniciado.

Puedes usar nombres descriptivos como `01-interfaz.png` y `02-dos-usuarios.png`. Actualiza los resultados del informe según las pruebas que hayas realizado.
